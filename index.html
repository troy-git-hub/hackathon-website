Getting Started

怎么用？从零上手

没有复杂的新手引导也没关系，照着下面四步走一遍，三分钟就能开始第一次「掉队急救」。

1

安装并启动 Echo

从下方「免费下载」拿到 Windows 安装包，双击一路下一步。装完从桌面或开始菜单启动 Echo。

→第一次启动会填资料：几道题（怎么称呼、在学什么、学习目标），存成本地 profile，之后启动自动跳过。关掉不填就不会进入主界面。
→首次运行加载模型：自动加载内置的 Whisper 转写模型（约 480MB，随安装包分发，不联网下载）。稍等片刻即可。
→没配 API key 也能用：没填 DeepSeek key 时自动退化为离线规则，界面照常可用；填了 key 才有完整的 AI 断点分析。
2

打开网课，Echo 自动开始听

正常打开腾讯会议 / Zoom / B 站 / 录播课，Echo 在后台自动抓取电脑正在播放的声音，实时转写并每 30 秒左右切出一个知识点。你什么都不用做，继续听课就行。

→默认抓「系统声音」：电脑放什么它就听什么，戴耳机也不影响。想改成听麦克风（比如线下课自己对着电脑），托盘右键 → 设置里改 ECHO_SOURCE=mic。
→怎么知道它在工作：主窗口会显示「老师正在讲 XX」和实时转写文字，声纹条跟着老师声音起伏；桌面宠物猫的表情也会随课堂变化。
3

没跟上？点一下「我掉队了」

主窗口有三个按钮，随时点击反馈你的状态：

✓跟上了：标记当前知识点已掌握，时间轴节点变绿。
?有点懵：标记当前知识点存疑，节点变黄，先记着不打断听课。
!我掉队了：核心动作。Echo 回看最近 5 分钟转写 + 时间轴 + 你的反馈，定位你从哪一步开始没听懂，输出断点位置、缺失的那一步、为什么卡，并用 30 秒把缺失步骤补上。
→快捷键：Ctrl+Alt+L 直接掉队（被占用时自动换 K / J / F9），听课不用伸手摸鼠标。
→补完继续听：断点页看完点「补上了，继续听课」，窗口缩回悬浮态，无缝回到课堂。
4

下课看「回响」，卡点自动进错题本

课程结束点「结束」，Echo 生成这节课的掌握度地图：一段话总结这节课讲了什么、时长 / 知识点数 / 转写字数、每个知识点 ✓⚠! 状态，以及掉队点一路追溯到该复习的前置。

→错题本自动沉淀：这节课所有掉队点按知识点收进错题本，重启后主页能回看、标掌握，不用手动整理。
→AI 出题巩固：照着你的错题让 DeepSeek 出选择题 + 简答题，带答案和解析；离线时也有兜底题。
→讲给 Echo 听：费曼式自测，不直接给答案，先听你讲再追问薄弱处——能讲出来才是真懂了。

FAQ

常见问题

Echo 需要联网吗？+

转写完全在本地完成，安装包内置 Whisper small 模型。断点分析和 AI 功能默认调用 DeepSeek，需要联网；无网络时 Echo 自动退化为规则兜底，界面仍可正常使用。

会泄露我的课堂内容吗？+

音频和转写文本只保存在你的电脑本地。只有在你主动点击「我掉队了」或追问时，相关片段才会被发送给 LLM 进行分析，且只发送最小必要的上下文。

支持哪些网课平台？+

理论上支持所有能发出声音的软件：腾讯会议、Zoom、B 站、Coursera、网易云课堂、本地录播播放器——只要 Echo 能捕获到系统声音，就能工作。

我的电脑配置要求如何？+

Windows 10/11 均可运行。Whisper small 模型对 CPU 友好，内存建议 8GB 以上。转写时若遇内存不足报错，在设置里把 Whisper 线程数降到 2 或 1 即可。

快捷键被占用了怎么办？+

Echo 检测到 Ctrl+Alt+L 被占用时会自动切换到 K / J / F9 中的一个可用键，设置界面会显示当前实际生效的快捷键。
